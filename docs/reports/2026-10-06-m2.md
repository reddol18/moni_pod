# M2 report — 2026-10-06 (/gpu-start + in-pod TTL)

## Built
- `start.py` — `quote()` (read-only): resolves template client-side, prices GPU (catalog × count, per cloud) or CPU
  (per vCPU), adds running disk ($0.10/GB/month), checks TTL cap (8 h) and session budget ($2; committed spend of this
  session + new max). `execute()`: needs a user-minted token, creates the pod, writes the ledger.
- `registry.py` — reads an image's ENTRYPOINT/CMD from its registry (anonymous OCI pull) so the TTL wrapper keeps the
  original command (HQ condition C).
- `ttl.py` — `sh -c` watchdog + `exec "$@"` of the original argv; stop via runpodctl / curl / wget / python3 (UA set),
  `MONI_POD_TTL_METHODS` to force one path in tests; stop only.
- `guard.py` + `hooks/hooks.json` — `UserPromptExpansion` hook mints a session-bound, single-use, 15-min token when the
  user types `/moni-pod:gpu-(start|stop|extend)`.
- `sync.py` — ledger ← RunPod: records stops/starts done outside our commands; stop time from the pod's system log
  (`stop container` ts) > TTL deadline > now. `/gpu-status` runs it by default (`--no-sync` to skip). (HQ condition B, early)
- `settings.py` — `~/.moni_pod/config.json` (TTL 2 h / cap 8 h, budget $2).
- `commands/gpu-start.md`; CLI `quote`, `start`, `hook`, `status` (sync), network-volume note in status.
- ADR-0004 (generalized wrapper, client-side template, conservative max cost, extend → stop+resume).

## Findings fixed
1. RunPod API edge returns HTML **403 to requests without a User-Agent** (Python default UA) → UA added to the watchdog's curl/wget/python3 paths and to log reads.
2. Container stdout is gone after stop; the **system log** (`start container` / `stop container` ts) survives → used for sync.
3. `/v2/billing/pods`: `startTime` and `endTime` must be given together (400 otherwise) → client enforces it.
