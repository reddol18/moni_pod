## Part 1 — M5 (warnings, display) + hook performance

### Hook performance (HQ request after M4)
| Hook entry for an unrelated shell call | median (20 runs, Git Bash on Windows) |
|---|---|
| M4: `uv run … moni-pod hook` on every call | 359 ms |
| bash-builtin prefilter script | 115 ms |
| floor of any shell-form hook (`bash -c exit`) | 69 ms |
| **final: `if` filters — no process spawned** | **0 ms** |

The 50 ms target cannot be met by any spawned prefilter on Windows, so the final config uses `if` filters
(`Bash|PowerShell(*runpod*|*RunPod*|*moni-pod*|*moni_pod*)`, `Write|Edit(~/.moni_pod/**)`). Verified with a hook
trace: `ls`, `git --version`, a normal Write and a PowerShell call never reached the hook; `runpodctl pod create`
did (denied); a Write of a new file in `~/.moni_pod` did (denied). Matching calls cost ~360 ms. Accepted residual:
a shell redirect into `~/.moni_pod` is invisible to `if` (ADR-0002); key 2 (native prompt) still guards spending.

### Built

### Known limits (to state in the README)
- Text matching only: obfuscated commands, scripts the agent writes and runs, SDK calls inside Python files,
  another MCP client, and the web console are not seen. Shell redirect into `~/.moni_pod` not blocked.
- Serverless endpoints and network volumes are not locked or tracked.
- RunPod billing history posts ~1 h late; live reference is balance + spend rate (GraphQL, which RunPod is retiring
  in favour of REST v2 — watch for a v2 balance endpoint).
- TTL counts from container start; image pull before that may be billed. Container restart re-arms the full TTL.
- In-place extend needs SSH usable without a passphrase prompt (agent or no passphrase); Windows uses system OpenSSH.
- Community GPU may be gone on resume. Volume 0 → results wiped at TTL stop (warned; GPU default volume 20 GB).
- Session-end display is a desktop toast, not chat output (Claude Code discards SessionEnd output).
- Ledger-based numbers are estimates at creation-time prices; community prices can drift.
