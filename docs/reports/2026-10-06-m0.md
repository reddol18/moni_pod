## Deviations from PLAN (need HQ OK before M1)

1. **REST v2 instead of v1** (v1 retires 2026-11-15).
2. **Token minted by the user, not the agent** (ADR-0002): `UserPromptExpansion` hook mints a token only when the user *types* `/moni-pod:gpu-start`; PreToolUse returns **`ask`** on our CLI call, so the cost confirmation is Claude Code's native prompt, which the agent cannot answer. PLAN §4 had the agent write the token after confirming in chat.
3. Our commands call **our own REST v2 CLI**, not the official MCP. Lock = plain deny on MCP `create-pod|delete-pod|update-pod|*-cluster` and `pod-action` start/restart/terminate, runpodctl create/start/delete, raw REST/GraphQL mutations. **`pod-action stop` / `runpodctl pod stop` stay allowed** (only lower spend).
4. Idle Monitor: not attached (license), README link only.
5. Status line: opt-in via user settings (plugins cannot set it).
6. TTL = max continuous run per start (re-armed on restart); `/gpu-extend` mechanics decided in M2 (env change via update-pod resets the container).
7. SessionEnd warning = Windows toast + next-session reminder (screen output not reliable).
